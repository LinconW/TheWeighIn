# TheWeighIn
A FastAPI application that tracks and analyzes weight and calorie trends over time using structured data logging.

## What's the Big Idea?
Right now, the project focuses on logging entries, deleting entries, graphing weight data, and testing GUI workflows. Tkinter is being used as an early desktop prototype, but the long-term plan is to move to a more capable GUI or frontend framework once the API is more complete.

The broader goal is to build a flexible backend capable of handling trend analysis, average weight calculations, calorie tracking, graph generation, date-range filtering, and support for multiple clients including desktop, web, and mobile applications.

## Features

### Current Features

- Add weight and calorie entries
- Delete existing entries
- Store entries in a database
- Display weight data in a graph
- Basic Tkinter desktop GUI
- FastAPI backend with structured endpoints

### Planned Features

- Average weight calculations by date range
- Line of best fit for noise reduction and trend analysis
- Weekly and monthly summaries
- Improved GUI or frontend framework
- Better graph customization
- Calorie trend analysis
